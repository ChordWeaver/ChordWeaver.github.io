ChordWeaver 1.0.1

La versión con la que el programa se publicó como código abierto. Es también la más grande que tuvo: entraron tres cosas que antes no existían —el armonizador, el libro de teoría y todo lo que pasa cuando el programa deja de ser sólo una herramienta— y se reescribió la interfaz entera.

Descargar 1.0.1 ← Volver al inicio

Nuevas funciones

  • Armonizador: permite escribir una melodía y armonizarla automáticamente o en función de lo que el usuario decida.
  • Modo historia: un personaje siniestro te está observando; no sabés qué quiere, pero sí que eventualmente lo vas a encontrar…
  • Encuentros: al completar ciertas acciones comunes, ciertos personajes interactuarán con vos.
  • Logros: se añadió un sistema completo de logros, diseñado para guiarte por la app, llevarte a aprender cosas nuevas y probar tus habilidades en la música.
  • Libro de teoría: un libro que se autocompleta al descubrir cosas, y que guiará tu estudio sobre armonía, contrapunto y los misterios de la música.
  • Espíritu vagante: se añadió el espíritu de una leyenda del pasado, cuya historia no se ha descubierto aún. Su aparición es inminente.
  • Glow up: se rediseñó por completo la interfaz, con mejoras visuales y de uso enormes. Ahora todos los modos tienen su propio color y la app se cambia en función del mismo.
  • Easter eggs: se añadieron acciones ocultas en la app. Al completar todos los logros se revela un camino para completarlos.
  • Revisitar el pasado: se añadió un sistema para rehacer encuentros. Ahora el usuario podrá reiniciar la historia desde los logros (arriba a la derecha) y podrá repetir ciertos encuentros desde la configuración.
  • Tutorial: se añadió un tutorial para la primera vez que se accede a la app. Se puede omitir y repetir desde la configuración.
  • Cadencias legendarias: se añadieron tres cadencias de status legendario, junto a su propio color especial.
  • Títulos: se añadieron títulos ganables por el usuario. Ahora completando ciertas actividades se podrán obtener títulos resplandecientes para felicitar el trabajo logrado.
  • Optimización para PCs de bajos recursos: en la configuración se añadió un botón que recalibra el algoritmo para PCs donde el programa tarda mucho en dar soluciones.
  • Donación: se añadió un botón para poder donar al creador.

Cambios importantes

  • Coral rediseñado: se renombró el género clásico al barroco. El modo coral ahora se puede activar mediante un botón en la penúltima pantalla.
  • Más rápido que nunca: se optimizó drásticamente la generación de soluciones y la navegación.
  • Generador mejorado: se mejoró drásticamente la armonía y sobre todo el contrapunto del generador, además de mejorar los voicings en acordes dominantes y de reposo.
  • Gregoriano rediseñado: se rediseñó el modo gregoriano. Ahora utiliza la vox principalis y organalis, fiel a como se escribía en la época. El contrapunto ahora es consecuentemente mucho más fiel.
  • Historial mejorado: se rediseñó por completo el historial. Ahora muestra mejor la fecha, permite reproducción instantánea y muestra correctamente el modo utilizado.
  • Reproductor mejorado: se mejoró el reproductor. Ahora podrá hacer sonar las notas de paso.

Cambios relevantes

  • Se mejoraron los mensajes de error y se mejoró el rango de posibles soluciones.
  • Se compilaron archivos principales a Cython y se añadió al capítulo de ingeniería del libro.
  • Se mejoraron los pesos default y sus rangos en el generador. Ahora tienen más influencia, sobre todo en el modo de jazz.
  • Se mejoraron los voicings especiales y los voicings de 6 voces.
  • Se rediseñó la pantalla de generación y se mejoró la información que brinda sobre las soluciones.
  • Se arreglaron múltiples crasheos, timeouts y esperas larguísimas para conseguir una solución cuando se utilizan 6 voces con modulación e intercambios modales.
  • Se mejoró la lectura de los intercambios modales: ahora estarán en naranja.
  • Se ajustó la frecuencia de interdominantes en el jazz.
  • Se rediseñó el generador a nivel motor: ahora es más rápido, preciso y genera más y mejores soluciones.
  • Se mejoró la lectura automática y la toma de decisiones autónoma del organizador.
  • Se mejoraron las descripciones y la tipografía de todo el programa.
  • Se corrigió que las soluciones generadas no se guarden o se multipliquen accidentalmente en el historial.
  • Se rehizo el sistema de sonidos para permitir estructuras más complejas.
  • Se formó un estándar para animaciones 3D en la aplicación, empleado por el modo historia y los encuentros.
  • Se corrigieron ciertas incoherencias armónicas en el generador.
  • Se eliminó la posibilidad de que una 9na u 11na inviertan el acorde al aparecer en el bajo.
  • Se limitó el máximo de compases a 32, debido a que más que eso es matemáticamente imposible de brindar una solución algorítmicamente válida. Cambiar el algoritmo empeoraría cualquier solución menor a 32 compases y el riesgo no vale para nada la recompensa. El motor queda habilitado para intentarlo: el cambio sólo afecta la interfaz de usuario.
  • Se corrigió un error donde el historial adulteraba las soluciones generadas.
  • Se mejoró el sistema de generación de soluciones a múltiples compases. Ahora no elimina soluciones inválidas, sino que les da nuevas chances de corregirse solas.
  • Se añadió una carpeta de assets más un sistema para poder modificar parámetros sobre las imágenes según se necesite.
  • Se generó un context global para que otros desarrolladores puedan utilizar Claude Code más eficientemente. Primer paso para lanzar el producto como Open Source.
  • Se añadió un capítulo especial en el libro de teoría sobre la ingeniería detrás de la aplicación, de rápida lectura (y muy friki).

Cambios menores

  • Se cambió la frecuencia de muestreo a 44100 Hz para más calidad y mejores sonidos.
  • Se añadió ecualización a nivel de motor.
  • Se arregló un error donde la app se trababa al generar una nueva solución mientras otra estaba en curso.
  • Se corrigió el voicing 6/4 del V: ahora calcula las distancias con respecto al bajo correctamente.
  • Se corrigió un error donde el modo de torneo del motor podía desactivarse por error del usuario.
  • Se corrigió un error donde al aumentar el tamaño de la letra al máximo la app quedaba inutilizable.
  • Se corrigieron errores básicos del motor e interacciones de audio con la parte visual.
  • Se corrigieron ciertos voicings con saltos exagerados.
  • Se aumentó la probabilidad de ciertas cadencias especiales de cada género.
  • Se añadió un sistema de versiones para próximas actualizaciones.
  • Se corrigieron errores a la hora de exportar una partitura.
  • Se corrigió un error donde los silencios aparecían representados con un C.
  • Se corrigieron ciertos errores enarmónicos.
  • Se corrigieron tamaños de botones que no podían aparecer en la pantalla.
  • Se eliminó el modo eólico porque estaba duplicado con la escala menor natural.
  • Se corrigió un error donde el modo coral hacía quedar sin garganta a los bajos, porque los subía 2 octavas por encima del máximo.
  • Se corrigió un error donde volver a valores por defecto del algoritmo lo ignoraba por completo a nivel de motor.
  • Se corrigió un error donde a más de 16 compases la pantalla de generación se trababa (no afectaba la solución).
  • Se añadieron sistemas de story, para garantizar que ciertos eventos no ocurren cuando el usuario está realizando una acción que la interrumpa.
  • Otros arreglos de bugs menores.

New features

  • Harmoniser: lets you write a melody and harmonise it automatically, or according to whatever you decide.
  • Story mode: a sinister figure is watching you. You don't know what it wants, only that sooner or later you are going to meet it…
  • Encounters: complete certain ordinary actions and certain characters will come and talk to you.
  • Achievements: a complete achievement system, designed to guide you through the app, lead you into learning new things and test your musical skill.
  • Theory book: a book that fills itself in as you discover things, and that guides your study of harmony, counterpoint and the mysteries of music.
  • Wandering spirit: the spirit of a legend of the past has been added, and its story has not been uncovered yet. Its appearance is imminent.
  • Glow up: the interface has been completely redesigned, with enormous visual and usability improvements. Every mode now has its own colour, and the app changes along with it.
  • Easter eggs: hidden actions have been added to the app. Completing every achievement reveals a path to completing them.
  • Revisiting the past: a system for replaying encounters. You can now restart the story from the achievements screen (top right), and repeat certain encounters from the settings.
  • Tutorial: a tutorial for the first time you open the app. It can be skipped, and replayed from the settings.
  • Legendary cadences: three cadences of legendary status, with a special colour of their own.
  • Titles: titles you can earn. Completing certain activities now awards shining titles that celebrate the work you did.
  • Optimisation for low-end PCs: a button in the settings recalibrates the algorithm for machines where the program takes a long time to produce solutions.
  • Donations: a button to donate to the creator.

Major changes

  • Chorale redesigned: the classical genre was renamed to baroque. Chorale mode is now switched on with a button on the second-to-last screen.
  • Faster than ever: both solution generation and navigation were drastically optimised.
  • Better generator: the harmony and above all the counterpoint of the generator were drastically improved, along with the voicings of dominant and resting chords.
  • Gregorian redesigned: gregorian mode was rebuilt. It now uses the vox principalis and organalis, faithful to how it was written at the time, and the counterpoint is consequently far more faithful.
  • Better history: the history was completely redesigned. It shows the date better, allows instant playback, and correctly shows which mode was used.
  • Better playback: the player was improved. It can now sound the passing notes.

Notable changes

  • Error messages were improved, and so was the range of possible solutions.
  • The main files were compiled with Cython, and this was added to the engineering chapter of the book.
  • The default weights and their ranges in the generator were improved. They now carry more influence, especially in jazz.
  • Special voicings and six-voice voicings were improved.
  • The generation screen was redesigned, and the information it gives about the solutions was improved.
  • Fixed several crashes, timeouts and very long waits when reaching a solution with six voices plus modulation and modal interchange.
  • Modal interchange is easier to read: borrowed chords now appear in orange.
  • The frequency of secondary dominants in jazz was adjusted.
  • The generator was redesigned at the engine level: it is now faster, more precise, and produces more and better solutions.
  • The organiser's automatic reading and autonomous decision-making were improved.
  • Descriptions and typography were improved throughout the program.
  • Fixed generated solutions not being saved, or being accidentally duplicated, in the history.
  • The sound system was rebuilt to allow more complex structures.
  • A standard for 3D animation in the application was established, used by story mode and the encounters.
  • Certain harmonic inconsistencies in the generator were fixed.
  • A ninth or an eleventh can no longer invert the chord by turning up in the bass.
  • The maximum number of bars was limited to 32, because beyond that it is mathematically impossible to give an algorithmically valid solution. Changing the algorithm would make every solution under 32 bars worse, and the risk is not remotely worth the reward. The engine is still allowed to try: the change only affects the user interface.
  • Fixed a bug where the history altered the generated solutions.
  • The system for generating solutions across many bars was improved. It no longer discards invalid solutions; it gives them fresh chances to correct themselves.
  • Added an assets folder plus a system for adjusting parameters on the images as needed.
  • A global context was written so other developers can use Claude Code more efficiently. First step towards releasing the product as open source.
  • Added a special chapter to the theory book about the engineering behind the application — a quick read, and very nerdy.

Minor changes

  • The sample rate was changed to 44100 Hz for more quality and better sound.
  • Equalisation was added at the engine level.
  • Fixed the app freezing when generating a new solution while another was still running.
  • Fixed the cadential 6/4 on V: it now measures the distances against the bass correctly.
  • Fixed the engine's tournament mode being switchable off by user error.
  • Fixed the app becoming unusable when the font size was raised to the maximum.
  • Fixed basic engine errors and audio interactions with the visual side.
  • Fixed certain voicings with exaggerated leaps.
  • Raised the probability of certain special cadences in each genre.
  • Added a versioning system for future updates.
  • Fixed errors when exporting a score.
  • Fixed rests being drawn as a C.
  • Fixed certain enharmonic errors.
  • Fixed button sizes that could not fit on the screen.
  • Removed aeolian mode, which duplicated the natural minor scale.
  • Fixed chorale mode leaving the basses without a throat, by pushing them two octaves above their maximum.
  • Fixed restoring the algorithm's defaults being completely ignored at the engine level.
  • Fixed the generation screen freezing beyond 16 bars (it did not affect the solution).
  • Added story systems that guarantee certain events do not fire while the user is in the middle of something they would interrupt.
  • Other minor bug fixes.
